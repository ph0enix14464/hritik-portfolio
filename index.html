Featured project

My MSc dissertation, built around one idea: no detector catches everything.

SSRF Adaptive Defense Framework

MSc dissertation, Northumbria University London, 2026. Supervisor: Prof. Hamid Jahankhani.

No security tool catches everything, and mine didn’t either. So I didn’t stop at detection. I built a second layer that limits the damage when an attack gets through.

  1. Layer 1: the detector

    A Python and scikit-learn classifier that detects SSRF attempts.

  2. Layer 2: the policies

    Seven Kubernetes NetworkPolicies enforce Zero Trust (NIST 800-207), independently of the detector.

  3. The target

    OWASP WebGoat, a practice application built to be attacked, in 900 automated tests.

Caught by layer 1. 89% detection accuracy with 0% false positives.

Missed by layer 1. The attacks it misses are why layer 2 exists.

How the two layers fit together. An illustration of the idea.
